NOTE IT - SETUP ON YOUR COMPUTER WITH IIS
==========================================

WHAT IS IN THIS FOLDER
  index.html            the Note It web page
  api.ashx              the small server program (IIS runs it) that reads and writes the Excel files
  web.config            IIS settings (start page = index.html)
  App_Data\Users.xlsx   all User IDs  (sheet "Users")
  App_Data\Tasks.xlsx   all notes and tasks  (sheets "Notes" and "Tasks")

  IIS never lets anyone download files from App_Data, so the Excel files stay private.
  No database or extra software is needed.


STEP 1 - TURN ON IIS AND ASP.NET (one time)
  Windows 10/11:
    Start > type "Turn Windows features on or off" > open it, then tick:
      [x] Internet Information Services
          > World Wide Web Services > Application Development Features:
              [x] .NET Extensibility 4.8
              [x] ASP.NET 4.8
              [x] ISAPI Extensions
              [x] ISAPI Filters
    Click OK and wait for it to finish.
  Windows Server:
    Server Manager > Add Roles and Features > Web Server (IIS) >
    Application Development > tick ASP.NET 4.8 (accept the extra features it asks for).


STEP 2 - COPY THE FOLDER
  Copy the whole NoteIt folder to:   C:\inetpub\wwwroot\NoteIt
  (Any other folder works too - just use that path in the next steps.)


STEP 3 - CREATE THE APPLICATION IN IIS
  Start > type "IIS Manager" > open it.
  On the left: open your computer > Sites > right-click "Default Web Site" > Add Application...
     Alias:          NoteIt
     Physical path:  C:\inetpub\wwwroot\NoteIt
     Application pool: DefaultAppPool   (must be ".NET CLR v4.0", Integrated - this is the default)
  Click OK.


STEP 4 - ALLOW IIS TO SAVE THE EXCEL FILES (important)
  Open Command Prompt AS ADMINISTRATOR and run:

    icacls "C:\inetpub\wwwroot\NoteIt\App_Data" /grant "IIS AppPool\DefaultAppPool:(OI)(CI)M"

  (If you chose a different application pool, put its name instead of DefaultAppPool.)
  Without this the page shows "The server cannot write to the App_Data folder".


STEP 5 - OPEN IT
  On this computer:      http://localhost/NoteIt/
  From other computers:  http://<this-computer-name-or-IP>/NoteIt/
                         (find the IP with the command:  ipconfig  -> "IPv4 Address")

  If other computers cannot open it, allow web traffic through the firewall
  (Command Prompt as administrator):
    netsh advfirewall firewall add rule name="Note It (HTTP 80)" dir=in action=allow protocol=TCP localport=80


STEP 6 - FIRST LOGIN
  User ID:  admin
  Password: admin123
  You will be asked to change this password straight away - please do.


MANAGING USER IDs (ADMIN)
  Option A - in the app:  log in as an admin > "Users" button (top right).
     + New user, Edit (name, role, active, reset password), Delete.
     Only users with Role = Admin see this page.
  Option B - in Excel:    open App_Data\Users.xlsx
     Columns: UserID | Name | Password | Role | Active | Created
       UserID    what the person types to log in (not case-sensitive)
       Password  type a PLAIN password to create or reset one. The first time that person
                 logs in it is replaced with an encrypted value (starts with "sha256$").
       Role      Admin or User
       Active    Yes or No  (No = cannot log in, but their notes and tasks are kept)
     Do not rename the columns or the sheet. You may add extra columns of your own - they are kept.

  People cannot sign themselves up. A forgotten password is reset by the admin.


THE TASKS FILE  (App_Data\Tasks.xlsx)
  Sheet "Notes":  NoteID | Title | CreatedBy | Members | Created | Updated
                  Members = User IDs separated by commas, e.g.  kishore, yana
  Sheet "Tasks":  TaskID | NoteID | Task | AssignedTo | DueDate | Done | AddedBy | Created
                  DueDate as yyyy-mm-dd, Done = Yes / No
  You can read, filter or edit it in Excel. The app picks up your saved changes automatically.


IMPORTANT - EXCEL AND THE APP AT THE SAME TIME
  * While a file is OPEN in Excel, the app cannot save to it. Users will see
    "Tasks.xlsx is open in Excel. Close it and try again." - close Excel and it works again.
  * If you edit a file in Excel while people are using the app, the app's newer changes
    can be overwritten when you press Save. Edit quickly, or make edits when nobody is using it.
  * To keep a backup, simply copy the App_Data folder.


WHO SEES WHAT
  * A note is visible to its creator and the people added to it.
  * A task that is assigned to someone is visible only to that person, the person who
    added it, and the note's creator. This is checked on the server, so it cannot be bypassed
    from the browser.
  * Admins manage User IDs; being an admin does not show other people's notes in the app.


SECURITY NOTE
  The page uses plain http://, which is fine inside your office network. Passwords travel
  unencrypted over the network, so do not open it to the internet without adding HTTPS
  (IIS Manager > Default Web Site > Bindings > add an https binding with a certificate).


TROUBLESHOOTING
  "Server error (404/500)... check that ASP.NET is enabled"  -> redo Step 1, then restart IIS
        (Command Prompt as admin:  iisreset)
  HTTP Error 500.19 / config error                          -> ASP.NET 4.8 is not installed (Step 1)
  "Cannot write to App_Data"                                 -> Step 4
  Page loads but login spins forever                         -> make sure you opened it through
        http://localhost/NoteIt/ and not by double-clicking index.html
